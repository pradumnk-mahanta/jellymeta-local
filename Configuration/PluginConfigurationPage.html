JellyMeta Local Configuration

Automatically match media folders against a local metadata repository to import NFO metadata and artwork (posters, banners, backdrops, logos).

Metadata Repository Path

The root directory on your server hosting the metadata folders.
Linux/Docker example: /metadata
Windows example: D:\Metadata

Matching Options

Automatically removes dates from folder names (e.g. transforms 2009-11-30 - FOLDER-1 to FOLDER-1) to match metadata directories.
Checks if the media folder matches, contains, or ends with the metadata folder, and vice versa.
Treats spaces, hyphens, underscores, and dots equivalently when matching folder names.
Allows organizing metadata folders into nested subdirectories (e.g. /metadata/Movies/FOLDER-1).

Overwrite Protection

When local metadata is matched and imported, locks only the populated fields (e.g. Title, Overview) to prevent them from being overwritten, while allowing downstream plugins (such as TheMovieDb or TheTVDB) to fill in missing metadata such as Cast, Artists, and Ratings.

Directory Structure Reference

Metadata Directory:
/metadata/
├── FOLDER-1/
│ ├── FOLDER-1.nfo (or movie.nfo / *.nfo)
│ ├── poster.png
│ └── banner.png
└── FOLDER-2/
    ├── FOLDER-2.nfo
    ├── poster.png
    └── banner.png

Media Directory:
/media/Type/Site/2009-11-30 - FOLDER-1/FILE.mp4
→ Matches FOLDER-1 and imports local metadata & artwork!
